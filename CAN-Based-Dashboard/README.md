# CAN-Based Dashboard

## Overview
A CAN (Controller Area Network) based dashboard project developed using embedded systems concepts. The project contains three ECU modules that communicate through the CAN network.

## Project Structure
- ECU1: Electronic Control Unit 1
- ECU2: Electronic Control Unit 2
- ECU3: Electronic Control Unit 3

## Technologies
- Embedded C
- PIC microcontroller
- CAN communication
- MPLAB X IDE

## Features
- Communication between multiple ECUs over CAN
- Modular ECU-based implementation
- Embedded firmware development

## How to Use
1. Open the required ECU project in MPLAB X IDE.
2. Configure the required hardware and CAN connections.
3. Build and program each ECU according to the project setup.
