# Car Black Box

## Overview
The Car Black Box is an embedded systems project developed using the PIC18F4580 microcontroller. It records and displays vehicle-related event data using peripheral interfaces.

## Technologies Used
- Embedded C
- PIC18F4580 Microcontroller
- MPLAB X IDE
- Character LCD (CLCD)
- ADC
- Matrix Keypad
- I2C and External EEPROM
- UART

## Modules
- CLCD interface
- ADC interface
- Matrix keypad interface
- I2C communication
- External EEPROM
- UART communication

## Project Structure
- CAR_BLACK_BOX.X: MPLAB X project and source files

## How to Use
1. Open the CAR_BLACK_BOX.X project in MPLAB X IDE.
2. Configure the required PIC18F4580 hardware and peripherals.
3. Build the project and program the microcontroller.
4. Connect the required display, keypad, and other peripherals according to the circuit design.
