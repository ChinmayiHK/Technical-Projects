# Red-Black Tree Implementation in C

## Overview
This project implements a Red-Black Tree, a self-balancing binary search tree, using the C programming language. It supports insertion, deletion, searching, and tree traversal while maintaining the tree's balancing properties.

## Features
- Insert nodes into the tree
- Search for a specified value
- Find the minimum and maximum values
- Delete a specified node
- Delete the minimum or maximum node
- Inorder, preorder, and postorder traversals
- Display inorder traversal with node colors
- Handle duplicate values
- Perform tree rotations and insertion rebalancing
- Free allocated tree memory before exiting

## Technologies Used
- C Programming Language
- Dynamic Memory Allocation
- Pointers and Structures
- Binary Search Trees
- Red-Black Tree Balancing
- Data Structures and Algorithms

## Project Structure
- `main.c` — Menu-driven program
- `tree.h` — Node structure, constants, and function declarations
- `insert.c` — Node insertion
- `fix_insert.c` — Insertion rebalancing
- `delete.c` — Node deletion
- `rotate.c` — Left and right rotations
- `search_minmax.c` — Searching and minimum/maximum operations
- `traversal.c` — Tree traversal, colored display, and memory cleanup

## Concepts Demonstrated
- Self-balancing binary search trees
- Dynamic memory allocation
- Pointer manipulation
- Recursive tree traversal
- Tree rotations
- Insertion and deletion operations
- Modular programming in C
